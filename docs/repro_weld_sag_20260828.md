## 1. solref/solimp 闭式推导

MuJoCo 文档的约束参考模型为：

```text
a_c + d (b v + k r) = (1 - d) a_u
```

其中 `r` 是约束位置残差，`a_u` 是不施加约束时的加速度，`d` 是 `solimp` 给出的阻抗，`a_c` 是约束后的加速度。静态、恒载时 `v=0` 且 `a_c=0`，所以 `d k r = (1-d) a_u`。正值 `solref=(τ, ζ)` 的官方参数化是 `b=2/(d_width τ)`、`k=d(r)/(d_width² τ² ζ²)`。若阻抗为常数且 `d=d_width`，代入得：

```text
r = (1 - d) a_u τ² ζ²
```

因此用户给出的 `d_max * g * τ² * ζ²` 少了一个补数：应为 `(1-d) * g * τ² * ζ²`。把 `d=0.95` 当常数时，修正后的数值是 20 ms: 0.196 mm、4 ms: 7.85 µm、1 ms: 0.491 µm、0.5 ms: 0.123 µm；用户表中的数值正是错误地乘了 `d`。对于 MuJoCo 默认 `solimp=(0.9, 0.95, 0.001, 0.5, 2)`，`d` 不是常数：`d(0)=0.90`、`d(width)=0.95`。故小残差近似应以 `d0=0.90` 为主，预测为 20 ms: 0.392 mm、4 ms: 15.7 µm、1 ms: 0.981 µm、0.5 ms: 0.245 µm；实际测量还会包含 table 自重、block 接触载荷和 `d(r)` 的非线性。

这也解释了质量独立性：在恒定重力载荷下 `a_u=g`，质量在 `F/m` 中消掉；但 table 受到 block 的接触反力时，会有约 `1+m_block/m_table` 的小修正，所以 M2 不是数学上完全相等。

依据：[MuJoCo Modeling — Solver parameters](https://mujoco.readthedocs.io/en/stable/modeling.html#solver-parameters)；[MuJoCo Computation — constraint parameters](https://mujoco.readthedocs.io/en/latest/computation.html#parameters)。
