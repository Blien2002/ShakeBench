## 1. 配色冲突的量化诊断

对第 6.0 s 帧逐区域采样，`R−B` 为红蓝通道差（正=暖，负=冷）：

| 区域 | 亮度 | R−B | 判定 |
|---|---:|---:|---|
| 机械臂本体 | 177 | +5 | 中性，正常 |
| 工作台木桌面 | 176 | **+54** | 过暖 |
| 护栏管 | 150 | **+43** | 实测 RGB(167,148,124)，这是脏卡其色，不是安全黄 |
| 墙纸 | 146 | +17 | 偏暖，且带提花花纹 |
| platen 孔阵列区 | 137 | **−32** | 过冷 |
| platen 顶面 | 116 | **−28** | 过冷 |
| 木地板 | 105 | **+93** | 极度过暖 |
| 坑口边框 | 91 | −23 | 偏冷 |
| 工作台框架/腿 | 51 | −9 | 正常 |
| 基坑最深处 | 15 | −6 | 过暗 |

**两个致命组合：**

1. **冷暖跨度 125 个单位**（木地板 +93 → platen 孔阵列 −32）。暖橙木地板 + 米黄提花墙纸 + 白色踢脚线是**家居配色**，而 platen、Stewart 机构、坑口包边是**工业冷灰**。两套配色语言在同一画面里对撞，这就是"不配"的来源。
2. **木地板亮度 105 vs platen 顶面 116，只差 11 灰阶**。相邻的两个最大面积元素在明度上几乎相同，只靠色相硬撞开。这是最糟的分离方式——明度不分离时，色相冲突会被放大。

**修复方向不是微调色值，而是把房间的材质身份从"住宅"换成"实验室"。** 见 S1。

## 2. 穿模清单

### 穿模 1：Stewart 活塞杆刺出 platen 侧缘（根因在第一轮的默认参数）

第 6.0 s 帧右侧放大可见：一根浅色活塞杆的上端穿透 platen 侧面并露在边界之外。

**根因是我在第一轮 P1 里给的默认值错了。** 我写的是：

```
platen_joint_radius（台面球铰分布圆半径，默认 0.55 m）
```

这个值是按方形平台估的，但你的 platen 是 `1.60 × 1.10 m`，**短边半宽恰好就是 0.55 m**。六个台面球铰正好落在短边边缘线上，再加上 `cylinder_radius`、球铰半径和斜置的杆身，必然刺出边界。

**正确做法：非方形台面的球铰不能用圆分布，必须用椭圆分布。** 约束条件为：

```
沿长轴：a + cylinder_radius + margin ≤ 0.80
沿短轴：b + cylinder_radius + margin ≤ 0.55
```

取 `cylinder_radius = 0.05`、`margin = 0.06`，则 `a ≤ 0.69`、`b ≤ 0.44`。建议 `a = 0.62`、`b = 0.40`。

还有第二个几何约束当前也没满足：**球铰中心的 z 必须低于 platen 底面，且留出球铰半径的余量**，否则球铰球体会从 platen 上表面冒出来。

### 穿模 2：右侧料架悬浮且立柱穿透搁板

第 12.0 s 帧右侧放大可见：料架四根立柱下端完全不接触地面，悬在空中；同时立柱穿出最下层搁板下方一截。

### 穿模 3：platen 侧裙可视厚度接近 0

左侧放大可见 platen 呈纸片状，看不到 `0.08 m` 的厚度。第二轮 R4 要求拆成"顶板 + 侧裙"，看起来只做了顶板。这既是视觉问题，也直接放大了穿模 1 的可见程度。

### 穿模 4：接触阴影贴片位置错误

第 9.0 s 帧可见：工作台下方只有**一个孤立的大椭圆**，位置在桌子中部偏右，和四条桌腿的落点完全对不上；左侧两条腿下方没有阴影。看起来像地面污渍。目标收纳盒和机械臂底座也没有阴影。

## S0 — 扩展视觉审计：加入冷暖与穿模检查

```
扩展 tools/visual_audit.py（第二轮 R0 建立的脚本），新增两类检查。

【A. 冷暖一致性】
支持从 configs/ 读一份区域采样表（区域名 + ROI 像素框），对每个区域输出：
  平均亮度、平均 R−B、RGB 均值
并计算全场景的"冷暖跨度" = max(R−B) − min(R−B)，安全黄类元素单独排除。

当前实测基线（第 6.0 s 帧）：
  木地板 亮度105 / R−B +93
  工作台木桌面 亮度176 / R−B +54
  护栏管 亮度150 / R−B +43
  墙纸 亮度146 / R−B +17
  机械臂 亮度177 / R−B +5
  基坑最深处 亮度15 / R−B −6
  工作台框架 亮度51 / R−B −9
  坑口边框 亮度91 / R−B −23
  platen顶面 亮度116 / R−B −28
  platen孔阵列区 亮度137 / R−B −32
  冷暖跨度 = 125

本轮目标：冷暖跨度 ≤ 50（安全黄除外），且任意两个大面积相邻表面的
亮度差 ≥ 25。

【B. 穿模的几何断言（不要用图像检测）】
在 tests/ 里加纯几何单元测试，比图像检测可靠得多：
1. 对一个完整 episode 的每一步，断言六个台面球铰点在 platen 局部坐标系下满足
   |x| + cylinder_radius + margin ≤ 0.80 且 |y| + cylinder_radius + margin ≤ 0.55
2. 断言球铰中心 z ≤ platen 底面 z − ball_radius
3. 断言六条腿的任意一段与 platen 的 AABB 无重叠（除球铰安装区）
4. 对所有静态设备（料架、机柜、护栏、工具车）断言其最低点 z 与地面 z 的差
   在 [−2mm, +2mm] 内，即"确实站在地上"
5. 对每个多段设备断言各段之间无非预期重叠（料架立柱不得穿出搁板）

任何一条失败就报出具体对象名、时刻和数值，不要静默通过。
```

## S1 — 房间材质身份重置（解决"不配"）

```
当前房间是住宅配色：暖橙木地板（R−B +93）、米黄提花墙纸、白色踢脚线。
这套配色和 platen / Stewart 机构 / 坑口包边的工业冷灰是两种材质语言，
放在一起必然不协调。修复方式不是调色值，而是换材质身份。

【材质替换】
1. 地面：木地板 → 环氧自流平地面（工业标准）
   - 中灰色，略带冷调，目标亮度 118、R−B +6
   - 表面有大尺度的浇筑纹理和轻微反光带，不要规律性方块接缝
   - 加区域划线（基坑周围的黄色安全边界）和轻微磨损/污渍
   - 备选方案：防静电架空地板（600 mm 方格 + 细缝），但方格尺度必须
     明显大于当前木地板贴图的重复周期，否则重复感更严重

2. 墙面：米黄提花墙纸 → 素色浅灰涂料，或工业夹芯板（带竖向接缝）
   - 目标亮度 195、R−B +8
   - 提花花纹必须完全去掉。如果保留一点纹理，只能是极低对比的涂料颗粒感

3. 踢脚线：白色 → 深灰或不锈钢色，目标亮度 92、R−B 0

4. 工作台台面：浅木色方格 → 深灰酚醛树脂台面（实验台标准材质）
   - 目标亮度 85、R−B −3
   - 理由不只是配色：深色台面能让浅色的收纳盒和 YCB 工件在视觉上明显跳出来，
     对感知任务的图像对比度也有利。这是双赢的改动。
   - 备选：拉丝不锈钢台面（亮度 145、R−B +2）

5. 墙上那个不明深色带孔小板：查清来源，如果是调试残留就删掉。

【完整调色板（本轮的执行标准）】
所有表面按下表分配，相邻大面积表面的亮度差必须 ≥ 25，
R−B 全部收敛到 [−25, +25]，只有安全黄例外：

  墙面（浅灰涂料）        亮度 195   R−B  +8
  机械臂本体              亮度 177   R−B  +5    保持
  安全黄（护栏/警示条/地线）亮度 175   R−B +185  唯一允许高饱和
  目标收纳盒              亮度 165   R−B  −8
  platen 顶面（阳极氧化铝）亮度 155   R−B −10   ← 提亮，成为最亮的大面积元素
  Stewart 活塞杆（镀铬）   亮度 130   R−B   0
  地面（环氧自流平）       亮度 118   R−B  +6   ← 从 105/+93 改
  坑口包边                亮度  95   R−B  −8
  踢脚线                  亮度  92   R−B   0   ← 从白色改
  工作台台面（深灰酚醛）    亮度  85   R−B  −3   ← 从 176/+54 改
  Stewart 外筒            亮度  72   R−B  −6
  惯性基座                亮度  62   R−B  −4
  工作台框架/腿           亮度  55   R−B  −5   保持
  基坑内壁 / 坑底         亮度  45   R−B  −5   ← 从 15 提亮

关键调整说明：
- platen 顶面从 116 提到 155，让它成为画面里最亮的大面积元素。
  任务发生在 platen 上，视觉焦点应该在那里。
- 地面从 105 保持在 118，主要改的是色相（+93 → +6）而非明度。
- platen 155 vs 地面 118 = 37 灰阶，platen 155 vs 台面 85 = 70 灰阶，
  两组都远超 25 的下限。

【验收】
跑 S0 的冷暖检查，冷暖跨度 ≤ 50。同时保持第二轮 R1 的层次指标
（IQR ≥ 60、std ≥ 55）不退化。渲同角度前后对比帧。
```

## S2 — 穿模修复

```
按 S0 建立的几何断言逐项修复。

【穿模 1：Stewart 活塞杆刺出 platen 侧缘】
根因：第一轮 P1 给的 platen_joint_radius = 0.55 m 默认值是按方形平台估的，
而 platen 是 1.60 × 1.10 m，短边半宽恰好也是 0.55 m，六个球铰正好落在
短边边缘线上，加上杆半径和斜置必然刺出。

修复：台面球铰改为椭圆分布，不是圆分布。
- 新增 platen_joint_semi_major（长轴，沿 1.60 m 方向）
  和 platen_joint_semi_minor（短轴，沿 1.10 m 方向）
- 约束：semi_major + cylinder_radius + margin ≤ 0.80
        semi_minor + cylinder_radius + margin ≤ 0.55
- 取 cylinder_radius = 0.05、margin = 0.06，建议 semi_major = 0.62、
  semi_minor = 0.40
- 基座球铰同样改椭圆分布，半轴取 0.85 / 0.60（基座平台比 platen 大）
- 第二个约束：球铰中心 z ≤ platen 底面 z − ball_radius，
  确保球铰球体完全在 platen 下方，不会从上表面冒出
- 启动时校验这些约束，不满足直接报错并打印超出量

【穿模 2：料架悬浮 + 立柱穿透搁板】
- 料架四根立柱最低点必须落在地面 z = 0（容差 ±2 mm）
- 立柱长度不得超出最下层搁板下沿（除预留的 40 mm 调节脚）
- 加调节脚圆盘 + 阴影贴片
- 顺便检查所有其他静态设备（机柜、护栏、工具车）是否有同类问题

【穿模 3：platen 侧裙厚度为 0】
第二轮 R4 要求拆成"顶板 + 侧裙"，当前只生成了顶板。
- 生成真实的侧裙几何，厚度严格等于配置的 0.08 m
- 侧裙按 S1 调色板与顶面拉开（顶面 155 / 侧裙约 105）
- 侧裙加 5 mm 倒角
- 修完后从低角度渲一帧，必须能清楚看到 platen 的厚度

【穿模 4：接触阴影位置错误】
当前只有一个孤立大椭圆浮在工作台中部偏右，和四条桌腿落点对不上。
- 检查 spawn_contact_shadow_decal() 是不是用整体 AABB 算了单个阴影，
  而不是逐对象生成
- 改为逐落点生成：四条桌腿各一个、目标收纳盒一个、机械臂底座一个、
  工件一个（每步跟随）、platen 一个（投在坑底）、护栏立柱各一个、
  料架调节脚各一个
- 阴影形状要匹配投影体的截面：方管桌腿用方形圆角阴影，不要用椭圆
- 阴影贴片的 xy 必须严格取投影体在 platen 局部坐标系下的位置，
  并随 C2 支撑运动同步；z 取 platen 顶面 + 0.2 mm
- 加一项测试：断言每个阴影贴片的 xy 与其投影体的 xy 偏差 < 3 mm
```

## S4 — platen 表面细节收口

```
1. 删掉 platen 顶面那两条横穿孔阵列的黑色细线。
   先查清成因：如果是贴图 UV 接缝，调整 UV 平铺或改用无缝贴图；
   如果是有意的分区线，重做成更细、更浅、位置对齐孔阵列网格的形式，
   不要像现在这样像裂缝。

2. 孔阵列的孔当前是纯黑圆点，像打印上去的。重新生成贴图：
   - 孔内壁上缘加一道高光弧（模拟倒角受光）
   - 孔内壁下缘最暗（亮度 45–60）
   - 孔口加一圈细的倒角亮环
   - 孔的排布要对齐 platen 边界，不要在边缘被半截截断
   在 platen 顶面亮度提到 155 之后，这些明暗层次才能真正显现。

3. 黄黑警示条：现在贴在侧裙上但只有黄块可见（因为侧裙亮度≈0）。
   S2 修好侧裙厚度、S1 把侧裙提到 105 之后，警示条会自然正常。
   另外把警示条改成连续的斜条纹带，不要现在这样的孤立矩形块。

4. 加速度计当前是两个孤立小方块。补齐：
   - 四角各一个，不是两个
   - 每个加一个底座圆盘和一段走线圆柱，走线汇到 platen 边缘再进坑
```

## 5. 一个需要你决策的取舍

S1 建议把工作台台面从**浅木色改成深灰酚醛**。这个改动比较大，理由有三条：

1. 配色上，浅木色台面 R−B +54 是场景里第二暖的元素，是冲突的主要来源之一。
2. 感知上，深色台面让浅色的 YCB 工件和收纳盒对比度大幅提升，对视觉策略有利。
3. 真实性上，深灰/黑色酚醛树脂是实验台的标准台面材质，浅木色更像家具。

代价是画面整体会变暗一些，且需要重新确认腕部相机画面里工件的曝光是否合适。如果你更倾向保留浅色台面，备选是**拉丝不锈钢**（亮度 145、R−B +2），能解决配色冲突但保留亮面，只是工件对比度收益会小很多。
