# ShakeBench 振動機制驗證實驗設計

版本：2026-09-09 / design-v1。狀態：**實驗設計，尚未實作或執行**。

本方案要決定 ShakeBench 是否值得作為獨立操作 benchmark 繼續投入。先驗證作用機制，再驗證策略價值；不以製造更大的滑移或更低的成功率為目標。本文的門檻是擬議的研究決策標準，不是真實硬體規格，也不修改既有正式評分規則。

## 1. 要回答的三個問題

1. **機械臂效應 H1**：相同的基座相對目標軌跡下，基座振動是否增加末端誤差或控制負擔？
2. **接觸效應 H2**：即使抓取前的桌面滑移很小，是否仍有抓持不穩、接觸中斷或放置反彈？
3. **策略價值 H3**：在同樣的動作頻率、底層控制器與任務預算下，振動資訊是否比一般目標運動預測帶來可重複的改善？

H1 成立只支持基座擾動的控制研究；要支持獨立的操作 benchmark，還需要 H2 的操作機制證據，以及 H3 或其他經驗證的操作能力差異。H3 不成立不能單獨證明振動資訊無用，也可能是所測策略沒有善用它。

## 2. 現有條件與固定項

依據 [目前任務設計](phase09_pick_place_states.md)、[物理設定](../robosuite/models/assets/shakebench_official_physics.yaml)、[Panda 控制器預設](../robosuite/controllers/config/robots/default_panda.json)及[觀測權限](../robosuite/utils/shakebench_providers.py)。執行前仍須記錄實際編譯與載入的設定；不能假設預設檔就是 runner 最終設定。

| 項目 | 主實驗設定 |
|---|---|
| 機器人／場景 | Panda；`direct_mount_v1`；基座與隔振桌承受同一平台激勵 |
| 主物體 | `wood_cube`，349 g；金屬 μ=0.30、桌墊 μ=0.90；固定幾何與質量，只比較接觸面 |
| 夾爪 | 既有摩擦 μ=1.0、相同閉合命令與力矩限制；不因振動提高夾力或降低摩擦 |
| 動力學 | 以 `official` 的 dt=0.0002 s、隔振器和接觸參數為參考；診斷變體另立非正式 contract |
| 控制 | 策略 20 Hz；底層 OSC 按既有物理步更新；保留偏置補償、增益與飽和限制 |
| 激勵 | 既有六軸多頻激勵；`frequency_scale=1`、`t0=0`、0.5 s 平滑啟動 |
| 強度 | `Gamma_commanded` = 0、0.60、0.95；沿用每 seed 的 2 s authored 校準 |
| 位置 | 工作台 xy：A=(-0.10,-0.13) m、B=(-0.04,-0.13) m；須先通過靜態可達性與碰撞檢查 |
| 觀測 | 主研究採 State 軌道；不把真值位姿實驗解釋成視覺抗模糊能力 |

這兩個位置是位置重複，不是獨立的振動樣本。M1、M2 的末端參考設在對應 xy 上方，初始高度取工作面上方 0.15 m；以完整夾爪幾何檢查全程間隙。若不可達或有碰撞，僅在試跑階段調整，記錄並凍結最終位姿與關節狀態後才執行配對矩陣。

主試驗不交叉鋼塊、麵包與輕木塊，以免同時引入形狀、慣量和質量差異。若主結論成立，再用其他物體驗證外推性。

**Gamma 的界線**：2 s 指令校準不是整段實際桌面加速度。每次另報完整激勵窗口的 authored 峰值、實測平台／基座／桌面六軸響應，以及隔振行程和數值有效性。不能把 `Gamma=0.95` 當成「實際桌面始終小於 g」。主階段不掃频、不改隔振器；之後若研究頻率效應，須分別控制位移幅值與加速度幅值，不能把它們混在一起。

## 3. 配對、種子與準備

- 開發種子固定為 910000–910007，共 8 個；確認種子固定為 920000–920039，共 40 個。IMU seed 分別為 930000–930007、940000–940039。這些是擬定的新診斷集合，不取代 official／knee states。
- 同一 seed 的 Gamma、策略、表面和位置比較共用同一組頻率、相位與 IMU 雜訊種子。Gamma=0 保留相同試驗 ID；不同位置與表面按 seed 分組統計。
- 所有初始姿態先在無振動下準備。開發期完成 2 個位置的可達性檢查、2 種表面的靜態抓取／放置，以及抓持快照與待放置快照的重播檢查。準備失敗不應歸因於振動；先修正共同控制器，再凍結設計版本。
- 正式試驗前輸出 compiled XML、實際控制參數、接觸 pair、版本／工作區 patch hash、初始狀態、程式與任務 contract hash。存在未提交修改時不能只記錄 HEAD。
- 成對分支從相同的**完整**快照恢復：qpos/qvel、act、時間、控制器目標／歷史、感測器狀態、隨機狀態和必要的求解器 warm-start。若無法完整恢復，重做相同的確定性準備序列並驗證起點一致；不能只複製物體位置。
- 分支開始後禁止修改物體 qpos/qvel 以维持期望軌跡。共用快照只在施加干預之前建立，不能按各振動條件的成功抓取結果分別篩選快照。

### M1：振動是否直接影響機械臂？

無物體接觸。先到達指定姿態，固定一個基座座標系下的 SE(3) 目標。每個策略步根據當前誤差生成修正命令，或使用明確的固定 absolute 目標介面；**不要假設持續零 delta 命令就是保持同一目標**，它可能在每步以當前姿態重設目標。保存送往 OSC 的實際目標軌跡。

三個 Gamma 共用初始關節狀態、目標與控制器。主指標是基座相對末端位置 RMS 誤差；姿態角誤差、P95／峰值誤差、每關節力矩 RMS／峰值／飽和時間占比為次指標。世界座標晃動只作示意。

常態誤差窗口取激勵後 1–6 s，同時報告 0–1 s 啟動暫態。任何早期失穩都保留，不能只統計撐到 1 s 的 rollout。平台／桌面限位觸發與接觸碰撞另行標記，以排除把限位撞擊誤認成一般抗振難度。

若只增加力矩、末端精度仍足夠，結論為「有控制負擔」，不能直接寫成「操作失敗增加」。不關閉重力／偏置補償來製造正結果。

### M2：排除「只是目標移動」的關鍵對照

從同 seed、同位置的 M1/Gamma=0.60 保存桌面相對基座運動，建立一条帶安全高度偏移的虛擬參考軌跡 `T_ref^B(t)`。此參考不參與碰撞。先固定原始 trace、時間基準和插值規則，再開始比較。

| 條件 | 基座 | 送入同一追蹤器的參考 |
|---|---|---|
| M2-S | 同一動態平台架構、零激勵；驗證實際基座近似靜止 | `T_ref^B(t)` |
| M2-V | 原六軸激勵 Gamma=0.60 | 完全相同的 `T_ref^B(t)` |

兩组每個物理／策略時間戳的基座相對參考必須相同。世界座標顯示位置由各自 `T_world^B(t)` 轉換；不把世界軌跡相同誤當作相對軌跡相同。控制器參數、歷史長度和計算預算相同，閉迴路輸出可以因實際誤差不同而不同。

使用 M1 相同的初始構型與完整快照。檢查兩组參考陣列 hash 一致、虛擬目標沒有接觸、夾爪不碰到桌面，以及 M2-S 實測基座運動。若零激勵平台因追蹤反作用仍明顯運動，該组應標為「零激勵」而非固定基座；需要固定基座診斷分支時另改 contract 並稽核編譯後拓撲。

主效應：`Δe = RMS_error(M2-V) − RMS_error(M2-S)`。若相對參考的位姿、速度與加速度都相同，追蹤誤差仍增加，便有超出目標軌跡本身的機械臂／底層控制效應。

**解釋範圍只有非接觸追蹤。** 不把物體強制回放到夾爪裡，也不把虛擬目標實驗的結果當成完整抓取成功率。基座固定、工作台獨立振動的實體操作可作後續對照，但其接觸與慣性條件不同，不能稱為全程軌跡嚴格匹配。

### M3：低滑移是否仍使抓取困難？

同一木塊、相同位置 A，只切換 metal／mat。採用相同的目標運動預測抓取策略 P-predict（第 6 節），振動從接近之前開始，持續至驗證結束。一次接近／閉合嘗試，用於機制診斷；完整任務的重試能力另由第二階段測量。

成功定義為在 8 s 內完成抓取與抬升，並連續保持 2 s：物體最低點至少高於工作面 30 mm、無桌面／籃底支撐，物體相對夾爪漂移不超過 2 mm／2°。漂移以初次形成穩定雙側接觸時為參考；記錄短暫接觸中斷，不以單幀指尖接觸自行宣布掉落。這是局部 probe 的成功標準，不改寫正式 pick/place 評分。

必須記錄桌面相對滑移、基座相對物體運動、閉合瞬間末端相對物體速度、雙側指尖法向力、抬升過程相對漂移和碰撞。桌面滑移只在首次夾爪接觸之前統計，自靜態準備結束的位置計算峰值，不能把夾爪推動／提起物體算成振動造成的預抓取滑移。

預先將「低滑移」定義為該窗口峰值平面位移 ≤1 mm 且直立餘弦 ≥0.95。按完整 metal／mat 条件組報告符合比例與全組成功率；不事後挑出剛好低滑移的成功或失敗樣本來作因果比較。若預定 mat/Gamma=0.60 組無法普遍保持低滑移，明確說它沒有完成低滑移操弄，H2 的這部分證據不足。

這個實驗單獨仍不能排除目標相對基座運動；需與 M2、M4 一起解讀。桌面摩擦改變也會影響夾爪接觸前後的桌面作用，不能只用 metal/mat 成功率差宣稱基座效應。

### M4：已抓住後是否仍有振動特有的負擔？

使用同一個無振動抓穩、已抬離桌面的完整快照。物體不接觸桌面或籃體，不添加焊接約束；夾爪保持同一閉合命令。之後才施加三个 Gamma，末端目標保持基座相對固定。

主指標是 6 s 內物體相對夾爪的峰值平移漂移；姿態漂移、掉落、指尖載荷和末端誤差為次指標。用物體相對夾爪的相對變換計算，不使用世界位移。瞬間 >2 mm／2°標記為滑移事件；同時保留連續量，不能把該事件直接等同於整個 episode 失敗。

掉落 probe 定義：失去雙側支撐後，物體相對夾爪向下離開初始抓持位置超過 20 mm、連續 0.1 s，或撞到原本不應接觸的下方支撐面。先在靜態開爪釋放的校驗分支確認此判定能抓到掉落。

若目前夾爪非常穩、全組都不滑，接受該負結果；不臨時降低夾爪摩擦或力矩。可在後續研究另列經硬體依據支持的抓持裕量，但不是本輪的正結果。

### M5：放置收益是否來自振動資訊，而非單純多等一下？

從相同的無振動「已抓持、物體底面在籃底上方 10 mm、水平居中且幾何完整位於開口內」快照開始。激勵從 t=0 啟動，共同追蹤目標籃；t=5 s 後進入釋放窗口。沿用相同追蹤器、夾持命令及收爪路徑，只改釋放觸發。

三个條件：

1. **立即釋放**：t=5 s 發出開爪命令。
2. **運動感知釋放**：每 50 ms，在未來 0.5 s 內挑選預測物體相對籃底接觸速度最低的時刻；只使用當前／歷史公開 V2 狀態和因果模型，計入開爪延遲與下落時間。最晚 t=5.5 s 必須釋放。
3. **等候時間對照**：固定使用另一 seed 的運動感知條件所選等待時間，按 seed 順序循環錯配；與感知組有完全相同的等待時間集合，但不使用本 seed 的運動資訊。記錄來源 ID，先跑完整感知組再生成此組。

多頻六軸振動沒有單一可通用的「相位角」；此處研究的是相對運動條件。啟發式的開爪延遲、接觸時間估計和濾波參數只在開發種子調整後凍結。以錯配等待消除「只是多等了一段時間」的主要混淆；仍要報告實際釋放時的相對位姿、速度和預測誤差。

全部跑到 t=9 s，並以各自實際脫離夾爪後 3 s 的共同觀察長度比較。主指標為該窗口末端連續 0.5 s 滿足既有籃內支撐、包容和相對速度條件；次指標為釋放到穩定時間、反彈高度、離開籃體事件與接觸衝量。禁止在第一次 success latch 後立即停止觀察，以免漏掉後續反彈；歷史 latch 與窗口末端穩定性分別報告。

準備期須確認從開爪命令到物體脫離不超過 0.5 s。若某 rollout 到 t=6 s 仍未脫離，記為局部操作失敗，不將它排除以保持 3 s 的觀察窗口。若該延遲界線在靜態準備階段就無法滿足，先統一延長三組窗口並更新設計，再開始矩陣。

## 5. 測量規格與數值檢查

| 資料 | 採樣／保存要求 |
|---|---|
| 平台、基座、工作台、末端、物體的位姿與 twist | 每物理步計算摘要；200 Hz 保存時序，標明座標系與左右時間極限 |
| 關節命令、裁剪前後力矩、實際 actuator force | 每物理步計算 RMS／峰值／飽和；不可只用 20 Hz 的 recent_torques 代替 |
| 接觸力、接觸切換與衝量 | 每物理步處理；衝量是有效步長上的力積分；保留事件前後 ±0.1 s 的完整高頻 trace |
| 策略輸入／輸出及狀態機事件 | 原生 20 Hz；IMU 保持既有 200 Hz 視窗；記錄延遲與實際消耗時間 |
| 影片 | 各條件固定第一個 seed，另加按量化規則選出的中位／最差案例；影片只作解釋 |

主座標記號：W=世界，B=基座，T=桌面，E=夾爪；`T_X^B` 表示 X 在 B 中的姿態。姿態誤差採 SO(3) 相對旋轉角；不可直接相減 Euler angles。相對 twist 須含移動參考系的平移／旋轉項，不能簡單相減兩個世界線速度。

將末端誤差、桌面相對滑移、夾爪相對漂移三者分開。加速度來自同一物理時間點的解析／模擬運動學；若有限差分，標明取樣率和濾波方式。不要由 20 Hz 影片估算瞬時接觸峰值。

在開發種子的低／高強度各選 1 個有代表性的 probe，以 dt 減半的非正式數值分支重播；首選同一接觸密集的 M4 或 M5 配置。其他物理參數、策略 20 Hz 和激勵不變，重新檢查所有調度時刻。連續主指標差異應小於預定實用效應門檻的 10%，事件結論一致；否則先報數值敏感，不能拿該效應支持研究價值。力矩峰值／單步接觸峰值須另看衝量是否收斂。

另做 1 个跨進程完整快照／準備重播，以及 M2 的參考一致性、非接觸與零激勵基座殘差檢查。這些是實作完成後必跑的有效性檢查，目前尚未執行。

## 6. 第二階段：凍結策略，使用 40 個新種子

第一階段不是尋找最容易掉落的 seed。只依預先約定選擇強度：优先 Gamma=0.60；若該強度全部主機制指標低於實用門檻，再檢查 0.95。若兩者都未顯示清楚機制，暫不啟動大矩陣，記錄有限樣本下的證據界線。若只有 0.95 有效，結論必須限定於此強度。

確認階段先重複 M2：40 seeds × 2 位置 × 2 基座條件 = 160 次。若選中的強度是 0.95，需生成該強度新的 M1 參考資料，不能沿用 0.60 軌跡假裝匹配。再重複一個最主要的接觸機制：M3 為 240 次、M4 為 120 次、M5 為 360 次，均保留原三個 Gamma 和對照結構；選擇僅使用開發資料並事先登記。

完整 pick/place 採 mat/wood_cube、位置 A/B、每次最多 1200 策略步（60 s），保留既有恢復和重試規則。對照矩陣如下：

| 條件 | 激勵 | 高層策略 | 策略可用資訊 |
|---|---|---|---|
| T0 | 0 | P-predict | 與 V0 相同的公共 State 及因果歷史 |
| T1 | 選定 Gamma | P-predict | 同 T0；估計目標／籃體相對運動並預測接近與接觸 |
| T2 | 選定 Gamma | P-IMU | P-predict 加 V1 的帶噪基座 IMU；有實作的估計／補償，而非僅多餵資料 |
| T3 | 選定 Gamma | P-model | 相同主體加 V2 的支撐運動真值與因果模型；作資訊較完整的參考 |

40 seeds × 2 位置 × 4 條件 = **320 個完整任務**。P-predict 必須是具有歷史與速度估計的正常動態目標基線，不能刻意採用無記憶的弱控制器。不同策略共用同一底層 OSC、任務執行器、夾爪限制、重試預算；新增資訊使用位置要能逐項停用。所有策略的增益與預測參數都只在開發集調整，各自給相同調參预算；保留完整版本。

執行確認集前，在開發集為各策略完成 Gamma=0 的靜態健全性檢查；若補償在零振動就有不同的增益，增加各自靜態對照，不將原本較好的控制器誤認為振動資訊收益。主矩陣不預設 T2/T3 的排序。

T0−T1 表示振動下的任務退化，T2−T1 表示可實際量測資訊的改善，T3−T1 表示較完整支撐資訊的改善。T3 不等於已知未來物體軌跡；V3 的 authored 未來激勵亦不等於未來接觸結果。V3 暫不加入，避免首輪成本過大。

若主張策略會選擇振動相關的時機，必須在確認集重複 M5 的錯配等待對照；只有 T2/T3 高於 T1 不足以單獨證明特定機制。若只有 P-model 有效，結論應限定於真值資訊參考，不能宣稱 IMU 可部署方案已成功。

## 7. 統計與繼續／轉向標準

所有表格報每 seed 的配對差。對 40 個獨立 excitation seed 以 cluster bootstrap（10,000 次重抽、固定分析 seed=950000）計算 95% 區間，將同 seed 的兩個位置和所有對照一起重抽；同時計算配對失敗／成功轉換計數。不把物理步、接觸點或位置重複當作獨立樣本。

每個 probe 只指定一個主指標（M1/M2=位置 RMS；M3=抓取成功；M4=峰值夾爪相對平移；M5=窗口末端穩定成功）。確認前登記被選中的接觸 probe。次指標作機制解釋，不能在許多指標中事後挑最顯著者當主結論。多個確認性正向檢驗採 Holm 校正；同時公開未校正區間及效應量。

以下門檻是本設計的**實用效應量**，須在開發結束、確認集開跑前凍結：

| 證據 | 擬議門檻及解釋 |
|---|---|
| H1 追蹤負擔 | M2 配對 RMS 增量 ≥2 mm 且區間下界 >0；小於此值的顯著差仍不能單獨證明操作需求 |
| H2 抓持 | M4 峰值相對漂移的配對增量 ≥2 mm 且區間下界 >0；或預先登記的成功率主指標退化 ≥10 個百分點 |
| H2 放置／抓取 | 對所選 probe，成功率配對退化／時機收益 ≥10 個百分點，區間排除零；須同時滿足其操弄與有效性檢查 |
| H3 操作價值 | T1 較 T0 成功率下降 ≥10 個百分點；T2 或 T3 較 T1 改善 ≥10 個百分點，並通過登記的確認性檢驗 |

門檻不是自然常數。若末端誤差僅 2 mm 卻遠小於任務容差，應以操作結果為準；若 T1 已接近滿分，不能強求 10 個百分點改善，再事後更換任務來「通過」。完成時間、重試次數和控制負擔保留為次指標，可支持重新定位的後續研究。

確認後有四種合法結論：

1. **繼續獨立操作 benchmark**：有非單純目標滑移的機制證據，完整操作退化具有實用意義，正常動態目標基線不足，而振動感知策略有可信改善。仍需後續跨物體、控制器與未見頻譜驗證，不能宣稱相對所有動態環境都獨一無二。
2. **轉為抗振控制評測**：H1 清楚，操作／接觸效應很弱；價值主要在精度、力矩或控制裕量。
3. **併入動態操作擾動集合**：有足夠精度的結果顯示主要難度可由一般運動追蹤處理，額外振動效應低於實用門檻。
4. **證據不足**：區間同時包含零與實用門檻、策略能力不足、操弄失敗或數值敏感。40 个種子不保證檢出 10 個百分點差異；不得將「不顯著」寫成「沒有必要」。如需擴樣，先據配對差異估計規劃新的獨立確認集與檢驗規則，不持續追加 seed 直到顯著。

第 3 種結論需要效應區間足夠窄，對相關主效應排除實用門檻；高成功率的天花板與極低成功率的地板都要明示。第一階段全面弱效應只能支持暫緩投入，不能直接證明等價。

## 8. 結果語義、產物與實作順序

完整任務沿用 [Phase 08R outcome 定義](phase_08r_failure_boundary_report.md)：policy abort/error、horizon exhaustion 和已登記的有限穿透違規保留在失敗分母；backend/nonfinite 執行故障是 invalid，需以相同 job identity 重試。未補齊的配對組不能悄悄刪除再宣稱矩陣完整。M1/M2 是連續控制 probe，不產生正式操作分數；M3–M5 的局部終點另記 `probe_outcome`。

所有診斷產物標記 `scoreable=false`，不寫入 official state asset 或修改其權威 hash。改拓撲、dt、參考／局部終點的分支建立獨立 contract，即使沿用 official 參數也不是正式 Phase 09 成績。

建議實作次序與責任邊界：

1. 新增獨立 `shakebench_mechanism_probe` runner，負責完整快照、M1/M2、時序 recorder 與配對 manifest；重用 `TaskSpec`、excitation、calibration、接觸 metrics。M2 目標只存在於 probe 層。
2. 加入 M3–M5 的局部狀態機與 probe evaluator；不改既有正式 success latch。M5 即使環境已 latch，probe 仍需能完成固定觀察窗口。
3. 完成前述有效性檢查與測量開銷 profiling，生成 224 个 planned jobs，再執行開發矩陣。
4. 輸出凍結的策略、選定機制／Gamma、確認矩陣和分析計畫，之後才開跑新種子。

這些 runner／開關是**待實作項**，目前不能用既有 CLI 直接執行全部設計，也沒有在本文提供假定已存在的命令。

每次輸出 manifest、逐 episode 摘要、時序／事件 trace、有效性結果與重播 hash。最終報告至少包含：M2 配對誤差圖、M4 指尖載荷與相對滑移時序、M5 三組穩定率及等待時間、T0–T3 成功率配對區間，以及失敗類型分布。正／負結果採相同呈現規則。

**成本**：先做 2–4 個代表性短 probe 的不渲染計時，記錄 simulated-seconds / wall-seconds、序列化和高頻事件保存成本。224 次短實驗不等於 224 次 60 s 完整任務；歷史 oracle 吞吐量不能直接套用。第二階段固定 320 次完整任務，加 M2 的 160 次、選定接觸 probe 的 120／240／360 次和必要參考資料生成，總量分支清楚記錄；只對固定案例渲染影片。
