# RoboCasa selected-object provenance

The visual meshes and textures in this directory were extracted unchanged from
the official `robocasa/robocasa-assets` Hugging Face dataset, `objaverse.zip`:

- `canned_food_18` → `food_can`
- `boxed_food_0` → `cookie_box`

Source: <https://huggingface.co/datasets/robocasa/robocasa-assets>
